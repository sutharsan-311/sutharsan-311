**Sutharsan K** is a robotics engineer at **Spotless AI**, building autonomous robots that navigate hospitals. The work sits where navigation, perception and real hardware meet, and most of it happens after the robot leaves simulation.

Sutharsan wrote [**nav2_config**](https://github.com/sutharsan-311/nav2_config), a live tuning GUI for Nav2 that lets you change navigation parameters on a running robot without a relaunch, and [**samowl**](https://github.com/sutharsan-311/samowl), an open-vocabulary 3D object detection and scene graph system for ROS2.

```
> ros2 node list --verbose
```

| node | what runs there |
|:--|:--|
| `/navigation` | Nav2 tuning, costmaps, controllers and lifecycle management on real robots |
| `/perception` | LiDAR and RGB-D pipelines, open-vocabulary detection and segmentation with OWLv2 and SAM |
| `/edge_ai` | Fitting models onto a Jetson Orin NX with TensorRT, and measuring what it actually costs |
| `/hardware` | Bringing up drivers and controllers with ros2_control |
